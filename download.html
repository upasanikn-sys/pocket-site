From download to running

  1. Download the installer from this page: no payment, no form, no account.
  2. Check it is the file this page describes: in PowerShell, Get-FileHash .\Pocket_3.2.4_windows_setup.exe should print the SHA-256 above.
  3. Run it. It installs Pocket for you alone, with no administrator prompt, and puts Pocket in the Start menu and on the desktop. Your 14-day full trial starts on first run, then the Free plan continues forever.
  4. Data lives in %USERPROFILE%\FinOSData — back up that folder and you have everything. Uninstall from Settings → Apps; your data folder is kept.
  5. Each new release is published here with its release notes; its installer updates Pocket in place. Back up before updating.

On a Mac: open the disk image and drag Pocket to Applications. Pocket is not yet notarised by Apple, so macOS blocks the first open: on macOS 15 or later, click Done, then open System Settings → Privacy & Security and click Open Anyway; on macOS 14 or earlier, Control-click Pocket.app and choose Open. Data lives in ~/FinOSData.

On Linux: on Debian or Ubuntu, sudo apt install ./Pocket_3.2.4_linux_amd64.deb, then open Pocket from your applications menu; on another distribution, run the AppImage under Alternative downloads. Pocket runs in a terminal window: leave it open while you use Pocket. Data lives in ~/FinOSData.
