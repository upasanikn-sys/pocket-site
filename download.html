From download to running

  1. Download the installer from this page: no payment, no form, no account.
  2. Check it is the file this page describes: in PowerShell, Get-FileHash .\Pocket_3.2.3_windows_setup.exe should print the SHA-256 above.
  3. Run it. It installs Pocket for you alone, with no administrator prompt, and puts Pocket in the Start menu and on the desktop. Your 14-day full trial starts on first run, then the Free plan continues forever.
  4. Data lives in %USERPROFILE%\FinOSData — back up that folder and you have everything. Uninstall from Settings → Apps; your data folder is kept.
  5. Each new release is published here with its release notes; its installer updates Pocket in place. Back up before updating.
