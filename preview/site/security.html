Current security limitations — read before relying on Pocket

Early access means honesty about what is not finished yet. The full detail lives in the security architecture.

  • The main database is not yet encrypted at rest by Pocket. It stays on your device; enable BitLocker / Windows Device Encryption. App-level encryption is scheduled on the roadmap (Q4 2026); the mobile apps now in internal testing already encrypt their database at rest.
  • The early-access installer is not yet code-signed. Only run a build received directly from us; we confirm SHA-256 checksums by email.
  • No independent security audit has been completed yet. One is planned before wide release; results will be published.
  • Backups are your responsibility. Pocket copies your database before every risky change and can restore one, and Founder Pro encrypts a backup for the cloud folder you choose. A local backup is a plain copy of a plain database, so protect your device like the vault it is.
